# Сайт школы «Лессония»

Одностраничный адаптивный сайт без сборки и зависимостей: HTML + CSS + JavaScript.
Открывается двойным щелчком по `index.html` или с любого статического хостинга — достаточно загрузить содержимое папки `lessonia` целиком.
Опубликован через GitHub Pages: правите файлы → в GitHub Desktop **Commit** → **Push origin** → через минуту изменения на сайте.

## Структура

```
lessonia/
├── index.html              разметка всех блоков
├── assets/css/styles.css   стили (палитра — из логотипа)
├── assets/js/data.js       ВЕСЬ редактируемый контент: контакты, направления, педагоги, отзывы, афиша, фото
├── assets/js/news.js       новости, собранные из Telegram-канала (72 поста)
├── assets/js/app.js        интерактивность: фильтры, онлайн-запись, формы, галерея, модальные окна
├── assets/photos/full|thumb  фото из Telegram (большие и превью), имя = номер файла из «все фото»
├── assets/video/           2 видео из канала
└── assets/img/             логотип, фавикон, скриншот отзыва из Telegram
```

## Как поменять контент — всё в `assets/js/data.js`

- **Статус набора** у направления: `status: 'open'` — «Идёт набор», `status: 'closed'` — «Набор закрыт»
  с плашкой «Следующий набор — с …» из поля `nextIntake: '2027-09-01'`.
- **Цены, расписание, возраст** — поля `price`, `schedule`, `age` у направления.
  Таблица «Стоимость обучения» (классы и питание) — в `index.html`, блок `id="prices"`.
- **Афиша** (`eventsRecurring`) — регулярные мастер-классы и открытые занятия; ближайшие даты
  на две недели вперёд считаются автоматически. Прошедшие события — `eventsPast`.
- **Педагоги** — `teachers`. Сейчас у карточек фото с занятий (портретов в канале нет):
  положите портрет в `assets/photos/thumb/` и укажите его номер в поле `photo`.
- **Отзывы** — `reviews` (18 с Яндекс Карт + 1 из Telegram).
- **Фотоальбом** — `gallery`: номер фото и категория.
- **Контакты** — `config` (телефоны, почта, ссылки на Telegram, VK, MAX, Яндекс Карты).

## Заявки с сайта

Онлайн-запись, «Оставить заявку» и «Заказать обратный звонок» отправляют JSON на адрес
из `config.formEndpoint`. Пока он пустой, сайт работает в демо-режиме: показывает подтверждение
и сохраняет заявку только в браузере посетителя. Чтобы заявки приходили школе, укажите адрес
приёмника — например, Formspree, вебхук CRM или свой сервер с Telegram-ботом.

## Что уточнить у школы перед публикацией

- статусы и даты следующего набора (сейчас закрыты: первый класс — с 01.09.2027, летний лагерь — с 01.06.2027,
  скорочтение, эмоциональный интеллект и «Юный историк» — по данным канала эти группы больше не набираются);
- цены и расписание кружков (взяты из постов канала и с nishkola.ru, часть — 2024–2025 годов);
- текст политики обработки персональных данных (в окне «Политика конфиденциальности» — короткая заглушка);
- портреты педагогов и, при желании, имена ведущих художественной студии, английского и танцев.

## Предпросмотр с локальным сервером

```
powershell -ExecutionPolicy Bypass -File .claude\serve.ps1
```

затем откройте http://localhost:8765/ (команду запускать из папки «Школа Лессония»).
